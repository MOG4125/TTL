**Note:** This list represents the comprehensive suite of packages and applications typically found in a default **Tuxtrans 20.04 b** installation. Actual installed packages may vary depending on installation options and subsequent updates. To view your exact system's installed packages, run:

```bash
apt list --installed
```

or

```bash
dpkg -l
```

All links open in a new tab and point to the official project or website for each application/package.
